# Jellyfin Organizer для Home Assistant

Аддон для HAOS, который разбирает имена фильмов и сериалов, готовит папки для Jellyfin и добавляет озвучки и субтитры в MKV. Исходные файлы сохраняются для раздачи.

## Установка

1. [Добавь репозиторий в Home Assistant](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FBrainDeLook%2Fjellyfin-organizer-ha).
2. Открой **Jellyfin Organizer** в магазине приложений и нажми «Установить».
3. Укажи папку завершённых загрузок и библиотеки Jellyfin, затем запусти аддон.
