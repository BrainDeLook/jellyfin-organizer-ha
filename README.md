# Jellyfin Organizer для Home Assistant

Аддон для HAOS, который разбирает имена фильмов и сериалов, готовит папки для Jellyfin и добавляет озвучки и субтитры в MKV. Исходные файлы сохраняются для раздачи.

- [Инструкция по установке и настройке](jellyfin_organizer/DOCS.md)
- [ZIP для установки как локального аддона](https://github.com/BrainDeLook/jellyfin-organizer-ha/releases/latest)

Для установки из приватного репозитория скачай ZIP и скопируй папку `jellyfin_organizer` в `local_apps` Home Assistant. Для импорта укажи папку завершённых загрузок и библиотеки Jellyfin.
