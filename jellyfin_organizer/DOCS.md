# Jellyfin Organizer

Аддон Home Assistant OS для Raspberry Pi 5 (`aarch64`). Веб-интерфейс открывается через Home Assistant. Отдельный порт и доступ к Docker API не нужны.

## Установка

1. [Добавь репозиторий в Home Assistant](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FBrainDeLook%2Fjellyfin-organizer-ha). Для установки из ZIP распакуй папку `jellyfin_organizer` в сетевую папку `local_apps` Home Assistant через Samba. На старых версиях Supervisor эта папка может называться `addons`.
2. В Home Assistant открой «Настройки» → «Приложения» или «Дополнения» → магазин. В меню магазина нажми «Проверить обновления», открой **Jellyfin Organizer** и нажми «Установить». Supervisor скачает готовый образ из GitHub Container Registry.
3. Создай входную папку и две папки библиотек на доступном диске. Укажи их в конфигурации аддона, затем запусти его и нажми «Открыть веб-интерфейс».
4. Открой релиз, проверь итоговые пути и дорожки. Если требуется уточнение, поправь название, тип, год или сезон, затем нажми «Сохранить план». По умолчанию импорт запускается вручную. Когда проверишь свои релизы, можешь включить `auto_import`.

[Установка локального приложения Home Assistant](https://contributors.home-assistant.io/apps/first-app/)

## Пример конфигурации

```yaml
input_folders:
  - /share/qbittorrent/completed
  - /media/NAS/Incoming
movies_folder: /media/NAS/Movies
shows_folder: /media/NAS/Shows
scan_interval_seconds: 60
stable_seconds: 90
auto_import: false
cleanup_input_folders: []
cleanup_whole_release: false
embed_tracks: true
preferred_audio: AniDUB
keep_original_audio_default: false
tokenclub_base_url: https://api.tokenclub.cc/v1
tokenclub_model: ""
tokenclub_api_key: ""
```

Заменяй пути на фактические. Для NAS или компьютера добавь сетевое хранилище в разделе «Настройки → Система → Хранилище» как «Медиа» или «Общая папка». Внутри аддона оно появится под `/media` или `/share`. Входные папки и обе библиотеки должны быть существующими и отдельными. Укажи Jellyfin родительские папки `Movies` и `Shows` как библиотеки соответствующих типов.

[Подключение сетевого хранилища к HAOS](https://www.home-assistant.io/common-tasks/os/#network-storage)

## Торренты и файлы

- В qBittorrent укажи отдельную папку для незавершённых загрузок и добавь в аддон папку завершённых. Путь зависит от конфигурации qBittorrent. Аддон следит за файловой системой и проверяет, что состав, размер и время изменения входных файлов стабильны. Папка завершённых нужна, поскольку пауза в скачивании может выглядеть как стабильный файл.
- Исходники торрентов остаются по прежнему пути. Для видео без ремакса аддон создаёт жёсткую ссылку там, где это возможно, или копию. При встраивании дорожек создаётся новый MKV. Видео и звук копируются без перекодирования. Некоторые встроенные субтитры MP4 переводятся в совместимый с MKV формат SRT.
- Похожий релиз определяет GuessIt. Дополнительно сравниваются название папки, год, номера сезонов и серий. Поддерживаются, например, `S02E03`, `1x03`, `S01E01-E02`, номера в скобках и папки «Сезон 02». Для абсолютной нумерации без сезона, конкурирующих релизов и некоторых сборников потребуется просмотр плана.
- Озвучки и субтитры подбираются по совпадающему имени или однозначному номеру эпизода внутри релиза. Язык и название берутся из суффикса, папки, известных команд или метаданных дорожки. Дорожка со значительным расхождением по длительности пропускается с сообщением. Указание дорожки по умолчанию зависит также от настроек проигрывателя Jellyfin.
- `embed_tracks: false` сохраняет дорожки рядом с видео по правилам Jellyfin. Исходные главы сохраняются при сборке MKV. Папки отдельных шрифтов для ASS, архивы, ISO, BDMV и DVD-структуры автоматически не импортируются.
- Если итоговое имя занято другим файлом, аддон просит проверить конфликт. Подтверждение плана привязано к текущему набору файлов. После изменения релиза аддон проверяет его снова.
- Если ты используешь поле «Первая серия», аддон нумерует файлы подряд по порядку обнаруженных серий. Для релизов с пропусками оставь это поле пустым или разбери неоднозначные файлы отдельно.

## Автоочистка входной папки

Добавь подключённую входную папку в `cleanup_input_folders`, например `/media/Cache`. Она должна быть указана и в `input_folders`. После успешного импорта всего релиза аддон проверяет готовые файлы, удаляет обработанные исходники и убирает опустевшие подпапки. Пропущенные дорожки, посторонние файлы и корневая входная папка сохраняются. Для импортов до версии 0.1.2 исходники сохраняются, поскольку в старых записях отсутствует проверка для очистки.

Указывай здесь отдельную папку для временных копий. Если qBittorrent скачивает или раздаёт файлы из папки, удаление исходников прервёт раздачу. По умолчанию список папок очистки пуст.

Чтобы после импорта удалялась вся папка релиза вместе с пропущенными дорожками и прочими файлами, включи `cleanup_whole_release: true`. Полная очистка применяется к отдельной подпапке одного релиза непосредственно внутри выбранной входной папки. Если папку делят несколько релизов, сохраняется обычная очистка обработанных файлов.

[Правила Jellyfin для сериалов](https://jellyfin.org/docs/general/server/media/shows/) · [Правила для фильмов и внешних дорожек](https://jellyfin.org/docs/general/server/media/movies/)

## TokenClub

Укажи в конфигурации HTTPS Base URL из кабинета провайдера, точный ID модели и токен. Адрес по умолчанию соответствует OpenAI-совместимому API TokenClub на `tokenclub.cc`. Кнопка «Предложить название через ИИ» отправляет только имя папки и имена первых файлов релиза. Предложение заполняет форму, план применяет пользователь. Распознавание и импорт работают при пустых полях модели и токена.

[Документация TokenClub](https://tokenclub.cc/docs.html)
